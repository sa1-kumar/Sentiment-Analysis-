# Twitter Sentiment Analysis 💬

This project performs sentiment classification on tweets using deep learning models like LSTM and BERT. It scrapes real-time tweets, processes them, and classifies sentiments into positive, negative, or neutral.

## Features
- Live tweet scraping using Tweepy
- Preprocessing with NLTK and regex
- Deep learning models: LSTM and BERT
- Visualizations of sentiment distributions

- Python 3.7+
- Tweepy
- Transformers (HuggingFace)
- PyTorch / TensorFlow
- Matplotlib, Seaborn

## Output
- Pie chart and bar chart of sentiment classes
- Word clouds for each class
